# NOVA — Theme Guide

A premium, minimal-luxury theme for Salla stores, designed for fashion,
accessories, beauty, home, and lifestyle brands that want a fast,
elegant storefront without compromising on functionality.

## What's included

**Homepage** — full-width hero slider, featured categories, brand strip,
Instagram-style gallery, and a newsletter signup, all rearrangeable from
your Salla dashboard.

**Product browsing** — a filterable, sortable product grid with grid/list
view toggle, color swatches, and three distinct product card styles you
can switch between in Theme Settings.

**Product pages** — an image gallery with zoom, a sticky "buy" bar that
appears on mobile as customers scroll, trust badges, and tabbed
description/specifications/reviews.

**Cart & checkout** — a full cart page with free-shipping progress,
coupon support, and live quantity updates — no page reloads.

**Fully bilingual** — Arabic (right-to-left) is the primary language
with complete English (left-to-right) support; every layout was built
to work correctly in both directions from day one, not adapted
afterward.

**Accessible by design** — keyboard navigation, screen-reader support,
and WCAG AA color contrast throughout, including places most themes
miss (like whether a color swatch's name is actually announced to a
screen reader, not just shown as a tooltip).

**Fast** — the JavaScript loaded on every page is under 3KB; everything
else loads only when a customer actually needs it.

## Customizing your store

Everything below is available from **Online Store → Themes → Customize**
in your Salla dashboard, no code required:

- Brand colors, fonts, and spacing
- Header behavior (sticky, transparent, announcement bar)
- Hero banner autoplay and timing
- Product card style and image ratio
- Which floating buttons appear (WhatsApp, scroll-to-top)
- Free shipping bar and coupon field visibility
- Custom CSS/JavaScript, if you need something beyond the built-in
  options

See `docs/SETTINGS.md` for the complete list.
